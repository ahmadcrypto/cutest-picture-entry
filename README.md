# Cutest Picture — Kitten Cuddling Duckling

Entry for make.fun's "Make the cutest picture" bounty ($250 in USDC).

A chubby baby kitten with big bright blue eyes and a tiny pink bow,
head tilted, cuddling a small fluffy yellow duckling — two friends
snuggled cheek to cheek among hearts and flowers.

## How it works

`main.py` (Python 3.13, standard library only) copies `cute.png`
byte for byte to `/output/entry.png`. No network, no third-party
packages. Two runs write identical bytes.
